# Security Policy

## Supported Versions

These versions are currently supported with security updates.

| Version | Supported          |
| ------- | ------------------ |
| 1.0.x   | :white_check_mark: |
| < 1.0   | :x:                |

## Reporting a Vulnerability

This is a test project; it is of no important use and is not handling any
private user information.  Consequently, no vulnerabilities are being accepted.

If you do find a vulnerability when scanning this project, I would still like
to know what it was and how to remediate it... but please do not expect any
monetary compensation.  However, if you find a vulnerability on the
dependencies, I think you should attempt to contact the maintainers of such
dependencies.
